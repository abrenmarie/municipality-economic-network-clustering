# Кластеризация муниципалитетов на основе динамических экономических сетей

## 1. Цель исследования

Цель проекта — выявить устойчивые типы муниципалитетов России по структуре потребительских расходов и исследовать их динамику во времени.

Муниципалитеты рассматриваются как вершины экономической сети. Сходство муниципалитетов определяется по структуре потребительских расходов, после чего для каждого месяца строится взвешенная kNN-сеть и выполняется выявление сообществ.

Итоговая задача состоит в выделении нескольких устойчивых экономических типов и анализе переходов муниципалитетов между ними.

---

## 2. Данные

Основной источник данных — муниципальные данные СберИндекса за январь 2023 — декабрь 2024.

Использованы категории потребительских расходов:

- Продовольствие
- Здоровье
- Маркетплейсы
- Общественное питание
- Транспорт

Категория «Все категории» не использовалась непосредственно в признаках.

Дополнительно в наборе данных присутствует показатель `market_access`, характеризующий потенциал внешнего рынка муниципалитета. В основной кластеризации он не использовался из-за наличия пропусков и его статического характера; показатель может использоваться для дополнительной интерпретации результатов.

Также подготовлен набор дорожных и железнодорожных связей между муниципалитетами.

---

## 3. Подготовка признаков

Для каждого муниципалитета и месяца рассчитаны доли пяти категорий расходов:

- `food_share`
- `health_share`
- `marketplaces_share`
- `catering_share`
- `transport_share`

Таким образом, каждый муниципалитет в каждый месяц представлен вектором из пяти признаков, характеризующих структуру потребления.

---

## 4. Построение экономической сети

Для каждого месяца:

1. Рассчитывается евклидово расстояние между муниципалитетами по пяти признакам;
2. Для каждого муниципалитета выбираются 10 ближайших соседей;
3. Формируется kNN-сеть;
4. Связи симметризуются;
5. Вес связи задаётся радиальной функцией:

`w = exp(-distance / sigma)`

где `sigma` определяется как медиана расстояний до соседей.

Основная мера сходства — евклидово расстояние.

Дополнительно проведена чувствительная проверка с использованием косинусного сходства.

---

## 5. Выявление кластеров

Для каждого месяца применён алгоритм Louvain.

Основная конфигурация:

- `k = 10`
- resolution = `1.5`
- seed = `42`

Количество найденных кластеров менялось от месяца к месяцу.

Всего за 24 месяца получено 521 месячный кластер.

---

## 6. Формирование устойчивых экономических типов

Месячные кластеры далее были представлены их средними профилями по пяти категориям расходов.

521 месячный профиль объединён методом KMeans.

При выборе числа типов сравнивались значения Silhouette и Calinski–Harabasz.

В качестве итогового решения выбраны 3 устойчивых экономических типа.

Для обучения KMeans использовались веса, пропорциональные числу муниципалитетов в соответствующем месячном кластере.

## 10. Динамика

Для каждого муниципалитета рассчитаны последовательные переходы между экономическими типами.

Всего получено 48 223 последовательных перехода муниципалитетов между соседними месяцами.

Доля сохранения типа:

- маркетплейсно-ориентированный → тот же тип: 88.1%
- диверсифицированный сервисный → тот же тип: 92.8%
- продовольственный → тот же тип: 82.7%

Наиболее заметное направление перехода вне диагонали:

- продовольственный → маркетплейсно-ориентированный: 16.0%

## 13. Ограничения

1. Используется структура расходов только по пяти выбранным категориям.
2. Эти доли рассчитаны внутри выбранных пяти категорий и не интерпретируются как доли от всех потребительских расходов.
3. Месячная кластеризация выполняется независимо для каждого месяца, поэтому сырые номера Louvain-кластеров нельзя интерпретировать как одинаковые типы во времени.
4. Три устойчивых типа являются результатом второго уровня кластеризации месячных профилей.
5. Матрица переходов отражает последовательные муниципалитет-месяц наблюдения. Один и тот же муниципалитет может учитываться в нескольких переходах за период.
6. Показатель `market_access` не включён в основную модель кластеризации.

## 14. Итог

В результате построена динамическая модель экономической структуры муниципалитетов, основанная на сходстве структуры потребительских расходов.

Для каждого месяца сформирована экономическая сеть, выполнена кластеризация Louvain, после чего месячные кластеры агрегированы в три устойчивых экономических типа.

Полученные типы различаются прежде всего соотношением расходов на продовольствие, маркетплейсы, общественное питание, здоровье и транспорт и демонстрируют различную устойчивость во времени.
